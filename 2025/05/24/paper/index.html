Overview of our SAO framework

Overall architecture of our proposed SAO. The input image is processed by the fine-grained scene understanding module to generate detailed text and visual representations. User instructions are parsed to extract the target object’s name and its global attributes. These are fed into the multi-source matching module to calculate matching scores for each object in the scene. A target-oriented concept scene graph is constructed based on the above information. Finally, the dictionary variable format of the concept scene graph is incorporated into the triadic prompt engineering module, guiding the LLMs to generate policy codes. These codes guide the robot to actively perceive the desired object from the scene by performing actions such as grasping or observing.
